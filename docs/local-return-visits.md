# 本地回访体验

## 用户入口

- 知识库首页：最近阅读、我的收藏。最近记录按主题去重，保留最近 8 项，区分详细内容与实验室入口。
- 文章与实验室顶部：收藏或取消收藏。同一主题的文章和实验室共享收藏；收藏打开详细内容，最近阅读返回最后访问的视图。
- 实验室顶部：恢复实验默认参数。重置只作用于当前实验室，不影响其他实验或收藏。
- 首页垃圾桶入口：二次确认后清除最近阅读、收藏和全部实验参数，保留语言及其他站点设置。

## 保存边界

使用浏览器 localStorage，无账号、数据库、上传或跨设备同步。数据属于当前浏览器及站点来源，localhost 与 GitHub Pages 不共享。
无痕模式退出、用户清理站点数据或浏览器回收存储，都可能使记录消失。

实验仅保存显式接入的参数、模式和选择，不保存播放状态、媒体对象、录音、文件、计算缓存、动画进度或拖拽中的状态。
文章内复用的互动组件不自动保存参数；同一组件只有在独立实验室的 LabSession 内才启用保存。

## 实现约束

- `audio-learning:v1`：经过主题白名单校验的最近记录与收藏。
- `audio-lab:v1:<topic>:<parameter>`：按实验室隔离的参数。读取时检查类型、范围与可选项，无效旧值使用默认值。
- 参数变化延迟 250 ms 写入，离开页面、切到后台或卸载时补写。恢复默认会阻止旧组件卸载时把已清除的参数写回。
- 本地存储被禁用或写满时提示保存失败，不阻断阅读与参数操作；此时不保证离开后的参数恢复。
- 最近阅读和收藏接收其他标签页的 storage 事件。已打开的实验参数不跨标签页实时联动。

本次不新增网络请求、运行时依赖或账号维护。
