# 音频技术，终于可以看懂了

你是否遇到过这些问题：看到 dBFS、LUFS、采样率、I2S、Codec、AEC、FFT 这些词，感觉每个都认识一点，但串起来就很难理解？想学习音频技术，却发现资料要么太浅，只讲“声音是什么”；要么太深，一上来就是公式和芯片手册。

“音频技术分享”就是为了解决这个问题做的一个学习网站：

https://cpw640530.github.io/audio-technology-sharing/

它面向对音频技术感兴趣但还没系统入门的读者，比如工程师、学生、音频发烧友、做硬件或软件开发的人。网站把音频知识拆成多个清晰分类：音频基础、音频硬件、音频软件、传统算法、AI 音频和应用场景。你可以像逛知识地图一样，从“什么是声音”开始，再逐步看到采样量化、麦克风、功放扬声器、系统音频架构、语音增强、空间音频、AI 识别等内容。

它的一个特点是“实验室”形式。很多概念不是只用文字解释，而是配合图解和交互页面。比如声音波形可以看到频率、振幅、相位如何变化；采样量化可以理解 PCM 是怎么来的；音频单位里会解释 dBSPL、dBFS、LUFS 为什么不能直接互相换算。相比死记术语，这更像是把音频链路拆开，让你看到每一步在做什么。

网站还支持中英文切换，适合一边看中文理解，一边对照英文术语。对于需要看芯片文档、系统接口、算法论文的人，这一点很实用。

如果你正在做智能硬件、音视频会议、车载声学、AI 语音、内容创作，或者只是想知道“为什么我的声音听起来不对”，这个网站都可以作为一个入门索引。
