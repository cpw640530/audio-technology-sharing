# 加载性能记录（2026-11-12）

## 本次修改

- 详细页和实验室使用 React.lazy + Suspense，首次进入时请求对应代码，保留独立 URL。
- AI 文章数据从实验室组件抽到 `src/content/aiArticles.ts`，阅读文章不再隐式引入五个交互演示。
- 按需加载失败时提供重新加载及返回入口；背景音乐位于路由边界之外，切页不重建播放器。
- 欢迎图使用 WebP 响应式候选，保留 PNG 回退、原始构图和宽高。
- 网页背景音乐改为 128 kbps MP3；时长仍为 353.071 秒。此项有损再编码，仅用于背景音乐，未修改教学对比 WAV。
- 保留音频 `preload="none"`，没有为了压缩首屏而取消用户已有自动播放逻辑；是否允许自动播放仍由浏览器决定。

## 浏览器抽样

生产构建由 Vite preview 提供，Linux headless Chrome，关闭浏览器缓存，每路由新建上下文。
桌面 1440×900；手机模拟 390×844、DPR=1、4 倍 CPU 降速。没有网络限速，访问的是 localhost，不是 GitHub Pages/CDN。
每页加载后等待 4 秒，再采集 60 个 requestAnimationFrame 间隔。仅一次抽样，不是统计基准，也不替代真机测试。
并行运行单元测试时的受干扰结果未用于下表。

| 页面 | 桌面 LCP 前→后 | 手机模拟 LCP 前→后 | 手机 RAF P95 前→后 |
| --- | ---: | ---: | ---: |
| 欢迎页 | 292→248 ms | 348→304 ms | 16.7→16.8 ms |
| 知识库首页 | 344→252 ms | 368→332 ms | 16.8→16.7 ms |
| AI 降噪实验室 | 224→184 ms | 328→400 ms | 33.3→16.8 ms |

RAF 间隔不是 INP，也不是实验动画的实际更新率。AI 实验室手机 LCP 在这次样本中变慢，因此不能声称所有页面首屏均提速。
桌面首页 RAF P95 从约 50 ms 变为 83 ms，AI 实验室从约 50 ms 变为 67 ms；三维背景/软件 GPU 绘制仍有波动，本轮没有改变背景形态或质量，不能把包体减少等同于绘制优化。

网络观察：欢迎页 JS 下载从 995,098 B 变为 349,702 B；知识库从 1,148,080 B 变为 503,029 B。
欢迎页和知识库未请求实验室 chunks 或降噪 demo.json；进入降噪实验室才请求该模块与数据。
自动播放被阻止、未手动播放时没有 MP3/WAV 下载；已获自动播放授权的浏览器仍可能开始下载背景音乐。
